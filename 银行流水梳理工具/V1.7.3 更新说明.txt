银行流水梳理工具  V1.7.3  更新说明
==============================================================================

【本版（V1.7.3）修的问题】
  1. 启用脱敏 + 勾「表头相同的工作表沿用同一套勾选」时，个别工作表不脱敏。
     原因：以前要求"表头签名完全一致"才继承；某张表自动识别的表头行不对（例如识别成第 28 行），
     算出来的签名就跟别的不一样，于是被跳过、一个单元格都不脱敏。
     现在改为：勾选复用 = 把勾选的那几列应用到**所有工作表**（某表没有该列名自然不命中）。
  2. 表头在很深的位置（如第 28 行、第 83 行）时脱敏失效。
     原因：逐段脱敏只看每段前 3 行找表头。
     现在改为：在该段内最多扫描 80 行，选"能匹配到最多目标列名"的那一行当表头。

【验证记录】
  - 三张工作表 DDD / HHH / QQQ，其中 QQQ 表头在第 28 行：
    三张表的「工单编号 / 玩家 / 联系电话」全部脱敏，工单类型与省份保持原样。
  - 复用关闭时仍然按各表自己的勾选处理，互不影响。

【本版（V1.7.2）新增】
  1. 相同表头的工作表可复用同一套脱敏勾选：
     - 选列窗口顶部新增开关「表头相同的工作表沿用同一套勾选」（默认勾上）。
     - 勾上时：切到表头结构相同的工作表，勾选状态自动继承；确定后这些工作表用同一套列。
     - 取消勾选时：每张工作表各自独立，只有你实际勾过的工作表才会脱敏。
     - 判断依据：把该表（含同表内的其它分段）表头列名排序后比对，完全一致才算"相同表头"。

【验证记录】
  - 三张工作表：一月/二月表头相同、客户表不同。
    勾「复用」：只在一月勾身份证号 + 客户表勾证件号码 → 三张表都按各自列脱敏。
    取消「复用」：只勾一月 → 只有一月被脱敏，二月与客户表保持原样。

银行流水梳理工具  V1.7.1  更新说明

【本版（V1.7.1）相对 V1.7.0 的变化】
  1. 脱敏可单独用于任意表格：
     - 表头识别增加通用规则（银行关键词一个都不命中时，取短文本列最多的一行作为表头），
       不再一律退回第 1 行；
     - 选列窗口新增「工作表」下拉与「表头在第几行」输入，改完点「重新读取」立即重建列表；
     - 空标题列显示为「（第 N 列，无标题）」，也能勾选。
  2. 脱敏不再依赖“流水区块”：没有金额列、切不出区块的普通表格，也会按所选列从表头下一行整列脱敏。
  3. 支持一张表里堆多张不同表头的表：按整行空白分段，每段用自己那一行表头匹配列名。
     选列窗口会把其它分段的表头一并列出，标注「｜第 N 段」。
  4. 支持多个工作表：窗口里可切换工作表分别确认表头行，各表按各自表头处理。
  5. 运行日志保留最近 5 次（当前 + _历史1~4），文件名带版本号；上次闪退的末尾仍会搬到新日志开头。
  6. 修复脱敏映射存不下来：源码此前漏了 import json，映射文件为 0 字节；本版已修，还原脱敏可用。

【验证记录】
  - 通用表（标题行 + 表头行 + 数据）：自动识别表头=第 2 行；只勾「身份证号」→ 该列脱敏，
    姓名 / 手机号 / 标题行均不变。
  - 同表两段不同表头：员工段脱敏「身份证号」、客户段脱敏「证件号码」，互不影响。
  - 两个工作表：分别按各自表头脱敏成功。
  - 银行流水回归：7 .xlsx 脱敏 + 映射文件（1159 字节）+ 统计表均正常。
