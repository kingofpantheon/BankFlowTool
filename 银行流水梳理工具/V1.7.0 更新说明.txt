银行流水梳理工具 V1.7.0 更新说明
======================================================================

一、这一版改了什么
  业务逻辑与 V1.6.9 完全一致（51 项回归用例逐项对照通过），只加了"出事能查、源码不丢"。

  1. 程序一启动就自动写日志，每行立即落盘。卡死、闪退、被任务管理器结束，
     已经写下的内容都还在（V1.6.9 的日志只存在内存里，进程一没就全丢）。
  2. 未捕获异常、子线程异常、界面回调异常，全部连完整堆栈写进日志。
     这些在无控制台的 exe 里以前是完全静默的，什么都看不到。
  3. 界面超过 90 秒没有响应时，自动把所有线程的调用堆栈写进日志，
     能直接看出卡在哪一行、正在处理哪个工作表。
  4. 日志只有一个文件，就在 exe 同目录下，文件名带版本号：
         银行流水梳理工具 V1.7.0 运行日志.txt
     每次启动覆盖重写；如果上次是闪退/被强制结束（日志里没有"正常退出"标记），
     本次启动会把上次日志的末尾（最多 300 行）搬到新日志开头留档，
     所以"崩了马上重启"也不会把证据冲掉。
  5. 源码和图标已经打进 exe 里了。界面上点「导出源码备份」，
     桌面会多出一个文件夹，里面是当前版本的完整源码（.py）和图标（.ico）。
     界面打不开时也能救：
         银行流水梳理工具_V1.7.0.exe --export-source
     会在桌面生成同样的一份备份。
  6. 界面新增三个按钮：
         「日志存到桌面」   一键复制到桌面，直接发出来即可
         「打开日志文件」   程序运行中也能看（文件被占用时自动打开副本）
         「导出源码备份」   导出源码 + 图标
  7. 上次异常退出的话，下次启动会弹窗提示，并可一键打开日志。

二、目录里新增了哪些文件
  源代码 V1.7.0 增加运行日志.py   源码（UTF-8，可直接用记事本/VS Code 改）
  打包成EXE就双击我 V1.7.0.bat     一键打包（GBK）。已固定优先打包 V1.7.0 源码，
                                  并把源码和图标一起打进 exe
  银行流水梳理工具_V1.7.0.exe      单文件版（约 38MB），直接发给同事用
  V1.7.0 更新说明.txt              本文件

  注：V1.6.9 的 exe 已删除，避免误发旧版；V1.6.9 的源码和打包脚本保留着，
      万一新版本有问题可以回退对照。

三、怎么发给同事
  直接发「银行流水梳理工具_V1.7.0.exe」这一个文件即可，双击就能用。
  日志会自动生成在 exe 同目录，名字带版本号，双击即可查看。

  如果同事的电脑双击后没反应、或弹出
      "Could not create temporary directory!"
  说明那台电脑不允许程序往临时目录解包（常见于管控较严的内网机）。
  处理办法：把 exe 放到一个可写的本地目录（如 D:\工具\），
  或改用文件夹版（需要时随时可以再打一个）。

四、日志怎么拿
  日志就在 exe 同目录，名字带版本号。
  软件界面里点「日志存到桌面」，桌面会出现一个 txt，直接发回来最省事。
  注意：日志记录文件名、工作表名、行列数、选项和错误堆栈，不含单元格内容；
        但文件名本身可能含客户姓名，外发前请确认。

五、重新打包
  双击「打包成EXE就双击我 V1.7.0.bat」，脚本会自动找 Python、装依赖、打包，
  产物输出到本目录。图标取本目录唯一的 .ico 文件，源码和图标会一起打进 exe。

六、已知说明
  1. 新版打包环境里的 pandas 是 3.0.5，旧版打包时的版本可能不同。
     pandas 只用于读取旧版 .xls，主流程不依赖它，风险有限；
     建议先拿一份真实流水跑一遍核对结果，再全面推开。
  2. 同时开两个实例会互相覆盖同一个日志（第二个启动会清掉第一个的日志）。

补充（同一版本内更新，版本号不变）：
  4. 列的选择方式统一改成"从表头勾选"（不再手打列名）：
     - 勾选「启用信息脱敏」→ 点「选择文件（可多选）」→ 软件读出这份文件的真实表头，
       弹出勾选框列表 → 单击一行勾选/取消（可多选）→ 确定后开始处理。
     - 为什么这样改：手打列名写错一个字（多空格、全角括号、少一个"侧"字）就会找不到该列，
       以前只是静默跳过，结果"以为脱了其实没脱"。
     - 每次处理都会用当次文件的表头重新确认一遍，避免上次的列名在新文件里不存在。
     - 一列都不选会二次确认"继续处理等于不做脱敏"。
     - 脱敏算法、映射文件、还原流程均未改动。

  5. 「手动勾选（对手方流水自动识别失败时使用）」上移到「启用信息脱敏」上方：
     - 勾选后出现一个按钮「选择列（金额 / 对手方名称 / 对手方ID）…」。
     - 点开后先选一份流水文件，软件列出它的全部表头，每个表头一行、右边三个勾：
         金额 / 名称 / ID —— 一次勾完三类列，确定即可，不再分三次弹窗。
     - 主界面显示"金额：xxx ｜ 名称：xxx ｜ ID：xxx"，三项齐全显示绿色，缺项显示红色。
     - 找不到时仍然会跳过该区块并写日志（行为与之前一致，只是选择方式变了）。

  6. 选择窗口与多文件（同一版本内更新）：
     - 勾选窗口支持鼠标滚轮（原来只能用右侧滚动条）。
     - 多选文件 + 手动勾选/脱敏时，软件会先按「表头是否相同」把文件分组：
         同一种表头 → 只弹一次窗口；不同表头 → 一种表头弹一次窗口。
       每个文件按自己那一组的列处理，不再强制只能选一个文件。
     - 多表汇总 + 手动勾选同时勾选时，仍可多选文件；汇总表依旧生成。

  7. 选列窗口合并为一个（同一版本内更新）：
     - 删掉多余的「选择列…」按钮：选文件时会自动弹出选列窗口。
     - 勾选「手动勾选」+「启用信息脱敏」时不再连弹两个窗口（原来第二个会被第一个挡住、导致不处理），
       改为一个窗口里同时列出：金额 / 名称 / ID / 脱敏 四列勾选框，一次勾完。
     - 窗口带滚动条且支持鼠标滚轮。

  8. 细节修正（同一版本内更新）：
     - 删掉「启用信息脱敏」下那句红字提示（"接下来点选择文件时会先弹窗…"），容易让人误以为要先勾脱敏内容。
     - 还原脱敏的两个文件对话框现在会自动定位到「上次处理/上次保存映射」的目录，
       不用再自己翻文件夹找 脱敏映射_*.json。
