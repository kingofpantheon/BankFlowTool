# 银行流水梳理工具 V2.0.7

一款免费、离线的银行流水表格处理工具：自动识别多区块流水文件，清理金额列不可见字符（货币符号、千分位等），生成按对手方分类的统计表（含流入/流出/合计及对手方账户ID细分）。

同时提供**两种脱敏方式**，对应两种不同的用法：

|  | 口令加密 | 密码本加密 |
|---|---|---|
| 外网能否还原 | 能（有口令） | 不能（没有密码本） |
| 文件能否编辑 | 不能，改了签名就废 | **随便改** |
| 复制粘贴进新表 | 能解但会乱 | **照常换回** |
| 需要的附带文件 | 无 | 密码本（留在内网） |
| 适合 | 带出去只看 / 原样带回 | 带出去干活，回来对账 |

## 🆕 V2.0.7 更新内容

### 密码本加密：内网导出 → 外网随便改 → 回内网换回真身

**内网**

1. 勾「启用信息脱敏」→ 选「密码本加密」
2. 选文件 → 勾要换掉的列（勾哪列换哪列，没勾的原样保留）
3. 不用输口令，直接处理

产出两样：

```
7_已处理.xlsx                      ← 拿出去用
密码本_7_20261113_032126.json       ← 留在内网，别外传
```

代号长这样：`名-SKFPXB` / `号-EBZB7Z`。前缀按值的字符类型给（名/号/户/值/址）。
**同一个人、同一个地址、同一个对手方，代号永远相同** —— 所以按代号分组统计 = 按地址/按用户分组统计。

**外网**

改数字、删列、加行、把内容粘进新建的工作簿、复制几份分开算 —— 都行。
代号本身看不出是谁：密码本不在手上，也没有盐，算不出来。

**回内网**

1. 点「还原脱敏」，选外网弄完的文件
2. 软件扫内容，检测到代号会问一次「用密码本查表换回真身吗？」
3. 选「是」→ 选那份密码本 → 完成

输出 `xxx_换回真身.xlsx`。

**只替换密码本里存在的代号**，实测混入 9 种用户改动：

```
真代号    名-ZPO262      → 二大爷        ✅ 换掉
我写的备注  已核对，无异常   → 已核对，无异常  ✅ 没动
我加的数字  12345         → 12345        ✅ 没动
我编的假代号 名-AAAAAA     → 名-AAAAAA     ✅ 没动（密码本里没有）
A-123456             → A-123456       ✅ 没动
2026-01-05           → 2026-01-05     ✅ 没动
改大小写   名-zpo262      → 二大爷        ✅ 换掉
```

### 口令加密（保留）

整表 FPE 加密，凭口令还原，带完整性签名。文件被编辑过 → 签名对不上 → 弹窗警告。

限制：这个模式下软件分不清「密文」和「你后来写的文字」（密文没有固定格式），
所以**要改数据就用密码本加密**。

### 其它改动

- 选列窗口：全选 / 全不选 / 反选；同名表头合并成一行（勾一次两列一起换）
- 表头标题行也可以一起换
- 每次处理生成独立密码本，文件名带源文件名和时间戳，不会混
- 脱敏与金额梳理互斥（勾了脱敏，求和/统计/汇总整组置灰）
- 已脱敏文件再次处理直接拒绝，不再产生 `_已处理_已处理.xlsx`
- 元数据（作者 / 最后修改人 / 时间）全部清空
- 单实例：不能同时开两个窗口，第二个会把已有窗口调到前台

## ✨ 主要功能

- 支持 Excel（.xlsx / .xls）和 CSV 格式流水文件
- 自动识别表头行、金额列、对手方名称列、对手方ID列、交易方向列
- 智能切分文件中的多个用户/区块（重复表头）
- 可选：清理金额列不可见字符，转为纯数值，确保公式可正常统计
- 可选：在每个区块末尾插入绝对值求和行（黄色高亮）
- 生成内部统计表（对手方统计汇总）：
  - 总计区域 + 各区块独立区域
  - 按对手方汇总流入/流出/合计，并横向列出每个对手方账户ID的细分统计
- 支持跨文件汇总
- 信息脱敏：口令加密 / 密码本加密两种方式，可逆，与金额梳理互斥
- 提供日志导出功能，便于排查异常

## 🔐 脱敏与还原怎么用

### 密码本加密（推荐，外网要改数据时用）

```
内网：勾脱敏 → 选「密码本加密」→ 选文件 → 勾列 → 处理
      得到 7_已处理.xlsx + 密码本_7_<时间>.json（密码本留内网）

外网：随便改、随便粘、随便复制

内网：点「还原脱敏」→ 选外网文件 → 自动检测到代号 → 选密码本 → 换回真身
```

### 口令加密（带出去只看时用）

```
内网：勾脱敏 → 选「口令加密」→ 选文件 → 勾列 → 输口令 → 处理
外网：只读，别改
内网：点「还原脱敏」→ 选文件 → 输当时的口令
```

## 📖 使用说明

1. 启动软件后，勾选所需功能（「清理不可见字符」默认不勾）
2. 点击“选择文件（可多选）”，选取银行流水文件
3. 等待处理完成，生成的文件在原始文件同目录下，文件名后缀为 _已处理.xlsx
4. 若勾选“生成对手方流水统计表”，处理后的 Excel 内会新增一个名为“对手方统计汇总”的工作表
5. 若同时处理多个文件并勾选“生成对手方流水统计表汇总文件”，会在第一个文件目录下生成 对手方汇总统计.xlsx
6. 脱敏按上文两种方式操作

## 🔧 兼容性说明

- 口令加密生成的文件，**V1.8.3 及以后**都能解（文件里记了盐）
- **V1.8.2 及更早**生成的文件没记盐，只能配合当时的 `脱敏金库_*.vault` 用老版本解
- **V1.7.x** 的历史文件是多代叠加产物，需走多代反查脚本

## 🛠 技术要点

- 自动识别表头行基于关键词匹配（支持银行常用列名）
- 金额列识别通过数值占比判断
- 区块切分基于重复表头行特征
- **口令加密**：格式保留加密（FPE，swap-or-not 构造），HMAC-SHA256 作轮函数，数字/大小写字母/汉字各自成域，标点原样保留；密钥 = PBKDF2-HMAC-SHA256（20 万次）+ HKDF 域分离
- **密码本加密**：`HMAC-SHA256(盐, 值)` → base32 前 6 位 + 类型前缀，单向、同值同代号、跨文件稳定
- **完整性**：口令加密整表内容多重集的 HMAC-SHA256，写入文件 `description`
